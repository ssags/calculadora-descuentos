# Calculadora de Descuentos Secuenciales

Aplicación web simple para calcular **descuentos aplicados uno después de otro** sobre un monto inicial.

Funciona directamente desde el navegador, tanto en **computadora como en celular**, sin instalar nada.

---

## Qué permite hacer

* Ingresar un monto inicial
* Agregar descuentos por:

  * Porcentaje
  * Monto fijo
* Aplicar los descuentos de forma **secuencial**
* Activar o desactivar descuentos
* Ver el monto restante paso a paso
* Copiar el resumen
* Exportar el resultado como PDF

---

## Uso

1. Ingresá el monto inicial
2. Agregá uno o más descuentos
3. Ajustá tipo y valor
4. Revisá el resultado final
